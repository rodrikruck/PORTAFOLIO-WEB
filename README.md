# Portafolio web de Rodrigo Krück

Versión ampliada del sitio basada en el moodboard y en el documento de proyectos.

## Contenido actualizado

- Página principal con seis grupos de trabajo seleccionado:
  - Nequi
  - Jetour
  - Soledad — SAMA
  - Travesuras
  - Dime Que Sí
  - Contenido personal
- Videos de YouTube reproducibles dentro de la página.
- Galerías enlazadas a Instagram.
- Nueva página independiente de experiencia laboral.
- Diseño responsive para computadora, tablet y móvil.

## Archivos principales

- `index.html`: portafolio y proyectos.
- `experiencia.html`: experiencia laboral y empresas.
- `styles.css`: estilos, responsive y animaciones.
- `script.js`: menú móvil, animaciones de entrada y encabezado.
- `assets/`: fotografías extraídas de los documentos del proyecto.

## Abrir el sitio

Abre `index.html` en un navegador moderno.

También puedes iniciar un servidor local:

```bash
python -m http.server 8000
```

Luego visita `http://localhost:8000`.
